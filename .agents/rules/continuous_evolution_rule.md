# 项目可持续演进与开源工具吸纳规则 (Continuous Evolution & Open Source Ingestion)

## 核心原则
1. **统一规范适配**：任何引入的开源工具或外部脚本，最终转正时必须统一遵循 `BaseMayaTool` 接口标准，将输入输出统一为 `ToolResult`，并提供大模型可读的 `get_schema()` 契约。
2. **双向技术择优互哺 (Bidirectional Upgrade)**：
   - **如果本项目现有模块更先进**（如更健全的 `UndoChunk`、OpenMaya 2.0 高性能加速、统一深色主题、字符串自然排序）：用项目底层库重构并替换新工具中的脆弱私有代码。
   - **如果新工具的核心算法/数学逻辑更先进**（如更精巧的动力学解算、四元数插值、高维网格哈希）：将其核心算法提取下沉至 `maya_toolkit.core` 公共库，甚至作为升级版本替换掉项目内的老旧实现。
3. **开源礼仪与版权保留**：在引入外部开源工具时，务必保留原工具的作者署名、开源许可证及出处链接，并在 `README.md` 或迁移记录中明确致谢。
