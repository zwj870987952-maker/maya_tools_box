## 恢复前

- 读取 PLAN/state/日志及实际文件/Git diff。
- 其他执行者/进程是否仍在运行：
- heartbeat 实际状态、ID、线程：

## 完成与证据

- 完成单元、实际文件、哈希/验证报告：
- 实际 Git SHA；未提交则列暂存/未提交差异：
- 失败、跳过和待验收，不得声称通过的项目：

## 半成品

- 当前单元具体阶段：
- 最近命令/退出码/错误报告位置：

- 已完成外部动作、重跑风险和核对方式：

## 下一步

- 第一条恢复动作/命令：
- 前置条件、输入与预期产物：
- 需用户回复的具体操作：
- 未完成单元、材料/依赖/环境问题：

## 收尾

- 保存检查点及最后实际额度：
