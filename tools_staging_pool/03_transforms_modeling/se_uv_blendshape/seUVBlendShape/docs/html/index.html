seUVBlendShape Plug-in Documentation¶

Version: 3.0

Author: Scott Englert

Welcome to the documentation home page for the seUVBlendShape plug-in for Maya. Below are links to all the different topics for this tool. The most up to date documentation can be found on the seUVBlendShape homepage.

Please read the End User License Agreement (EULA) prior to installing.

What’s New¶

Version 3.0 of the plug-in was rewritten to use a different algorithm so that greater performance on the GPU override of the deformer is achieved. It is still backwards compatible if opening up previous scenes from version of Maya before 2022. The new algorithm will be used when a new target is added or an existing target is rebound. New attributes were added to the node to store the new data while the old attributes still exist for compatibility.

Note

Deformers using the new algorithm will not work in Maya versions before 2022. So if you plan to open your scene in older versions, do not add or rebind the target so the original data is retained.

Additionally, set membership is supported in 2022 version of the plug-in for GPU override. Finally, the Python module is compatible for Python 2 and 3. Older versions of the plug-in for Maya 2015 through 2017 are no longer being supported or supplied. Please contact me if they are still needed.
