# Maya 简化角度显示工具

这是一个专为高效多对象角度管理设计的Maya工具，支持多对象录入、Maya节点存储和实时显示控制。

## 🎯 核心特性

- **单一计算模式**：专注于自定义轴向夹角计算
- **多对象管理**：支持同时录入和管理多个对象组
- **Maya节点存储**：所有数据存储在Maya大纲的专用节点中
- **对象按钮系统**：每个对象组对应一个管理按钮
- **激活编辑模式**：点击按钮激活对象组进入编辑状态
- **实时显示控制**：鼠标点击时刷新所有角度值

## 🔧 界面布局

### **轴向设置区域**
- **当前轴向显示**：显示物体1和物体2的当前轴向设置
- **轴向选择菜单**：为两个物体分别选择轴向（X/Y/Z轴及其负向）

### **录入选择区域**
- **录入选择按钮**：将当前选择的两个物体录入为新的对象组

### **对象组管理区域**
- **对象按钮列表**：显示所有已录入对象组的管理按钮
- **滚动布局**：支持管理大量对象组

### **控制按钮区域**
- **计算角度**：计算所有对象组的角度并更新显示
- **实时显示**：激活/关闭鼠标点击刷新功能

## 📝 使用流程

### **1. 录入对象组**
1. 选择轴向设置（物体1和物体2的轴向）
2. 在Maya中选择两个物体
3. 点击"录入选择"按钮
4. 工具会在Maya大纲中创建专用节点存储信息
5. 界面中生成对应的对象按钮

### **2. 管理对象组**
- **激活对象组**：点击对象按钮激活该组（按钮变绿色）
- **编辑模式**：激活后，修改轴向设置会实时更新该组
- **取消激活**：再次点击按钮取消激活（按钮变灰色）
- **覆盖更新**：辅助节点以覆盖方式更新，不会产生重复节点

### **3. 角度计算和显示**
- **手动计算**：点击"计算角度"按钮
- **实时显示**：
  - 点击"实时显示"按钮激活（按钮变绿色）
  - 在Maya中进行任何鼠标点击操作都会刷新所有角度值
  - 再次点击关闭实时显示功能

## 🏗️ Maya节点结构

### **容器节点**: `AngleDisplayContainer`
- 在Maya大纲中创建的主容器节点
- 存储所有对象组的根节点

### **对象组节点**: `AngleDisplayContainer_group_XXX`
- 每个录入的对象组对应一个子节点
- 存储对象组的完整信息：
  - `groupId`: 组标识符
  - `object1/object2`: 物体名称
  - `axis1/axis2`: 轴向设置
  - `isActive`: 激活状态

### **辅助节点**
- 辅助线：`group_XXX_line1`, `group_XXX_line2`
- 定位器：`group_XXX_locator`
- 角度标注：自动生成的annotation节点

## ⚡ 核心功能详解

### **轴向计算系统**
```python
# 支持的轴向选项
- X轴 (+X): 物体的正X轴方向
- Y轴 (+Y): 物体的正Y轴方向
- Z轴 (+Z): 物体的正Z轴方向
- 负X轴 (-X): 物体的负X轴方向
- 负Y轴 (-Y): 物体的负Y轴方向
- 负Z轴 (-Z): 物体的负Z轴方向
```

### **数据持久化**
- 所有信息存储在Maya场景文件中
- 重新打开工具时自动恢复所有对象组
- 自动检查物体是否仍然存在
- 无效的对象组会被自动清理

### **实时更新机制**
- 监听Maya的选择变化事件
- 鼠标点击时触发角度刷新
- 仅更新激活状态的对象组
- 高效的覆盖式节点更新

## 🎮 操作示例

### **示例1：录入多个对象组**
1. 设置轴向：物体1选择"Y轴 (+Y)"，物体2选择"Z轴 (+Z)"
2. 选择cube1和sphere1，点击"录入选择"
3. 设置轴向：物体1选择"X轴 (+X)"，物体2选择"Y轴 (+Y)"
4. 选择cylinder1和cone1，点击"录入选择"
5. 现在有两个对象组，各自独立管理

### **示例2：编辑对象组设置**
1. 点击第一个对象组按钮激活（变绿色）
2. 修改轴向设置为"负Y轴 (-Y)"和"X轴 (+X)"
3. 辅助线和角度数值自动更新
4. 点击按钮取消激活（变灰色）

### **示例3：实时监控**
1. 激活"实时显示"功能（按钮变绿色）
2. 在Maya中移动、旋转任意物体
3. 点击Maya视图中的任意位置
4. 所有激活对象组的角度值立即刷新

## 📊 技术优势

### **性能优化**
- 按需计算：只计算激活的对象组
- 覆盖更新：避免节点堆积
- 延迟执行：使用evalDeferred优化刷新

### **数据安全**
- Maya原生节点存储
- 场景文件保存时自动持久化
- 自动检查和清理无效数据

### **用户体验**
- 直观的按钮状态反馈
- 清晰的轴向显示
- 简化的操作流程

## ⚠️ 注意事项

1. **物体命名**：确保物体名称唯一且稳定
2. **节点管理**：请勿手动删除AngleDisplayContainer节点
3. **性能考虑**：大量对象组时建议关闭实时显示
4. **场景清理**：删除物体前请先取消对应的对象组录入

## 🔧 故障排除

**Q: 对象按钮不响应？**  
A: 检查对应的物体是否仍然存在于场景中

**Q: 工具重启后对象组丢失？**  
A: 确保场景文件已保存，容器节点包含在场景中

**Q: 实时显示不工作？**  
A: 确保有激活的对象组，且实时显示按钮为绿色状态

**Q: 角度计算不准确？**  
A: 检查轴向设置是否正确，尝试重新录入对象组
