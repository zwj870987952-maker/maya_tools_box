# 真实 Maya 人工验收（not_run）

1. 只用临时目录、备份场景和可审阅 Python/MEL 脚本；先保持一个有未保存修改的 Maya 场景，调用 launch_candidate.show_ui()。
2. 拖入 MA/MB/实际 FBX 和脚本，测试内部排序、自然名称/时间/大小排序、移除列表项、双击打开（有未保存修改必须拒绝）、执行全部/所选模式及日志右键清空。
3. 默认隔离运行，验证脚本顺序、当前dirty场景/选区/时间/Undo不变，备份字节与原文件一致，另存ASCII打开无误。多目录同名文件、已有备份/输出应在执行前拒绝。
4. 覆盖MA/MB先生成原始字节备份，实际打开确认文件格式/脚本结果；FBX覆盖拒绝但另存MA可用。Save按钮新目录/空目录/非法目录/已有目标行为与文档一致。
5. 测试失败跳过/停止、取消途中、超时；检查已完成输出和遗留文件，脚本本身的外部写入不能撤销。脚本换scene应拒绝自动保存。
6. 已保存干净场景选择interactive测试需要界面的脚本；结束重新打开来源，恢复有效选区/时间/AutoKey，Undo被清空须知。测试unknown清理显式选项和MGTools autosave关闭/打开的原兼容问题，生产使用条件记录版本。
7. 结果满意后才执行promotion计划，候选留池内，GUI/生产场景/跨版本均未声称通过。
