# 减选偏移 Maya 验收

1. 备份场景中三个控制器A/B/C均有密集邻帧/多通道动画，用候选launcher load_tool().show_ui()打开，检查原数值字段、正负小数、两按钮、重复开关窗口，不自动启动原脚本或删其他selectFramesTool。
2. 单次offset=5应A不动，B/C+5；批量offset=5应0/5/10。以源脚本无碰撞稀疏键案例作对照。offset1/-1/0.5与密集键用候选验证每键平移恰好一次、数量/值/切线和Euler连续性，避免原逐键碰撞。offset0不写键。框图只选部分键时仍移动全部对象键，符合源工作方式。
3. objects显式顺序与Maya默认ls返回顺序分别检查；候选不自动展开DAG后代。父/子同时需要处理时明确选入。GUI once最后选余下对象/键，batch选最后对象/键；API默认不变选择。Maya未启用selection-order tracking时不要宣称选择点击顺序已保证。
4. dry_run节点/键/选择/时间/Undo栈不变；执行一次Undo/Redo恢复键。次序中后项锁定应整批拒绝，前项不得先写。引用、驱动键/timeWarp、层图、输出到未指定或首个不動对象的共享曲线拒绝；同offset共享曲线仅移一次，batch冲突拒绝。
5. 无动画对象仍可作为次序一员；少于两个对象/错误参数明确提示。生产加权切线、动画层先烘焙流程/复杂rig和跨版本真实Maya验收记录后才按promotion清单晋级。当前mayapy结果不是GUI实测。
