What is Noodle?

Noodle is a tool that aims to automatically create overlapping animation for you.
The goal of Noodle is to work in as many situations as possible, with the least amount of work from the user.

While there are many tools out there that may do something similar, Noodle aims to be as simple as possible, whilst still being robust and dependable. Noodle is also actively being developed and will continue to get better with each version.

How Noodle works

Noodle works by baking the existing animation of your controls to a series of proxy controls and offsetting the timing of those controls, whilst also hooking a physics system to them.

Known Limitations

There are still many limitations to Noodle, which we will try address in future versions, here are some of the known limitations:

  • Only works on FK chains (a series FK controls, E.G. a tail, FK arm controls, etc.).
  • Currently still rotational, no translational overlap.
  • It does not work on FK chains where rotation on controls rotates multiple joints by the same value (I.E. Squirrel rig from Animation Mentor).

Getting started

Noodle requires playback set to Play Every Frame for the physics component to work

  1. Launch Noodle.
  2. Select rig controls (The order matters, unless using the Hierarchy option, in which case you only need the base control selected).
  3. Load Controls.
  4. Hit the Overlap Setup button to create an overlap setup.
  5. Adjust the sliders in the Settings tab to achieve the desired result.
  6. When you have the desired result, in the Bake tab, hit the Bake Setup button.

Advanced Options

Frame Range

The frame range in which Noodle will operate within. By default, Noodle will use the frame range of the timeline when the tool is launched.

  • Pressing the Frame Range button will reset the frame range to the timeline frame range.
  • You can manually input a frame range if desired.

Aim Vector

The local axis in which the FK chain points down. By default, Noodle will try to automatically determine the aim vector, this option is for the user to manually override in the event Noodle cannot determine it.

End Control Aim Distance

This option allows you to adjust the distance of the imaginary endpoint control that influences the rotation of the last control in the FK chain. A lower value will mean the end control rotations will be more sensitive, whereas a higher value will mean less it will be less sensitive. By default, Noodle will use the average distance between each control in the FK chain to determine this value.

Settings

The settings tab has been organized so that the most important settings are at the top, and the least important are at the bottom. Users should work from top to bottom wherever possible.

Current Setup

This dropdown box allows you to switch the current setup to any other existing Noodle setup. The current setup is the one that the settings sliders will affect.

Use Physics

This toggles the current setup to either use or not use physics. If Use Physics is disabled, then the only settings slider available for adjusting the result is the Time Offset slider.

Time Offset

Time Offset will delay each subsequent control’s animation in order to achieve overlapping animation. A Time Offset value of 1 will mean a 1 frame delay between each subsequent control. E.G. tail01_ctrl’s delay is 0 frames, tail02_ctrl’s delay is 1 frame, tail03_ctrl’s delay is 2 frames, etc.
The more controls in the FK chain the lower this value tends to be. Common values range from 0.5 to 1.5.

Overall Stiffness

This setting will adjust the entire FK chain’s stiffness. A value of 1 will mean the FK chain is not influenced by the physics system (essentially the same as turning Use Physics off), any overlap contribution will be from Time Offset. Optimal values are between 0.4 to 0.7.

Base Stiffness

This setting will adjust the “base” control’s stiffness, the base control is the first control in the FK chain. This stiffness will gradually diminish down the FK chain. A value of 1 will mean the base control is completely stiff, whilst the next control will be slightly less stiff, and the one after that will be even less stiff, … and the end control won’t be affected by this value at all.
Base Stiffness and Overall Stiffness are additive with one another, so if Overall Stiffness was 1, then Base Stiffness will have no effect. Optimal values are between 0.1 to 0.6

Smoothness

This setting will control how smooth/soft the physics system behaves. A lower value will give a more snappy physics reaction, whereas a higher value will give a smoother/softer reaction. Optional values are between 1.5 to 3.0.

Damp

This setting will adjust how much damping there is in the physics system. Damping can help control wild fluctuations and artifacts in the results. Damp is very sensitive so values should be really small. Optimal values range between 0 to 0.05.

Tips

Below are some tips and best practices when using Noodle.

  • Disable cached playback whilst there are still “live” setups (before you bake them down).
  • Set playback speed to Play Every Frame.
  • Avoid dragging the time slider, just playback instead. You can drag the time slider forwards, but you will have to drag it to every frame without skipping any frames; skipping frames can cause issues with the physics system.
  • Sometimes the physics system needs a refresh, simply go back to the starting frame to reset the physics system.
  • If you are not using physics, none of the above applies.
