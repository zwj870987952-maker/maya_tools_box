Set of basic scripts for the OverRig animation method

Author: Pavel Barnev pavel_barnev2000@mail.ru 

How do I access procedures when I boot up?

create a file 

C:\Users\<USERNAME>\Documents\maya\scripts\userSetup.mel

	or, if there is one, add a line to it
	

source "D:/<path script location>/base_OverRig_scripts_V9_0/base_OverRig_scripts.mel";
global int $barnev_OverRig_RotateOrder = 0;
global string $path_to_JGLBN;
$path_to_JGLBN = "D:/<path script location>/base_OverRig_scripts_V9_0/misc/";
If in doubt, you can copy this strings from the shelf button

command list for hotkeys
	base_OverRig_scripts(1) - script menue (1,0 - color scheme)
	apply_ForwHierarhy(1) - create forward hyerarchy
	apply_ReverseHierarhy(1) - create reverse hyerarchy
	apply_LOH_Component(1) - create component snapshot
	apply_LOH_Fast(1) - create object snapshot
	apply_DoubleUzelGlobal(1) - create double global knot
	apply_DoubleUzelLocal(1) - create double local knot
	apply_Knot_Orient_Point(1) - create knot orient
	apply_PivotParentAnimation(1) - create pivot knot
	apply_parent_anim_across(1) - create parent across KNOT
	apply_parentConstrAnim(1) - create knot
	Lag_Key(1.2) - lag key (frames)
	apply_Fast_Bake() - bake
	apply_range_Fast_Bake() - bake on min-max or selected framerange(save outside keys)
	apply_Bake_to_layer() - bake to layer
	scale_selected_lock_or_joint(1.5) - local scale selected locator or joints
	apply_Parent_out() - parent to world
	apply_Parent_in() - parent inside
	apply_Swap_parent()- swap parent
	setKey_on_attach_attr(value) - set key on attach attr
	make_aim_from_selected(1) - create aim
	set_infinity_graphEditor("cycle") - set pre/post infinity ("cycle","oscillate", "linear", "constant")
	double_oscillate_keys(2) - oscillate period from timeslider
	copy_start_frame_to_end() - copy FIRST frame to LAST frame (need for cycling animations)
 	set_start_end_key() - Set keys on FIRST and LAST frame
	set_key_time_range("all") - set the same keyframe on the allocated time range ("all", "translate", "rotate", "channelbox")
	selKeys_by_timerange() - select current keyframe or selected framerange
	delete_keys_from_selected_or_timeslider()  - delete selected frames on all channel all selected objects
	time_slider_range(24) - toggle timeslider range
	set_currenttime_to_mid_selection() - move time slider to mid selection position
	create_normalised_locators_on_selected() - create locators on selected
	return_constrained_object(1) - select an object that is constrained selected one
	apply_rebike_3_or_more_object_to_IK - bake  3 or more FK to IK
	apply_objects_spline_IK(0) - bake 2 or more FK to spline IK
	apply_objects_spline_IK(1) - bake 2 or more FK to depend spline IK
	barn_copy_keys() - copy selected single animCurve frames
	barn_past_scaled_keys() - paste scaled to selected frames
	offset_keys_by_period(2) - shift keys by half period
	double_inv_oscillate_or_mirror(2, "x ", "x") - if keys selected - set inverse mirror keys by X axis for translate and X axis for rotate. Or set 1/2 inverse oscillate by (x,x) form
	apply_smart_parentConstrAnim(1) - the animation will be baked on smart locator
	apply_smart_PivotParentAnimation(1.5) - the animation will be baked on smart Offset locator
	apply_smart_Knot_Orient_Point(1.5) - the animation will be baked on smart Orient locator
	apply_Smart_Bake(0) - the animation will be baked with this object keyframes
	apply_Smart_Bake(1) - the animation will be baked with this SMART KNOT keyframes
	delete_constraint_attributes_on_objects(`ls-sl`) - delete Constraint channels from objects
	BP_arc_tool_menue() - Open menue Arc Polish tool
	assign_Sword_pivot_System(1) -  assign Sword pivot System
	assign_Sw_System -  assign Sword  System
	barn_execute_convert_rotation_order("xyz") - convert rotation order
	assign_jiggle_bone_soft(1) - assign physical point on selected objects
	barn_sel_set_member("OverRig_rig_objects") - select all rig source objects
	barn_sel_set_member("OverRig_knots") - select all Knots and setera
	barn_fast_bake_source_obj_and_delete_knots() - select all rig source objects, bake, and delete knot objects
	barn_fast_bake_min_max_or_range_source_obj_and_delete_knots() - select all rig source objects, bake min-max or selected framerange (save outside keys) , and delete knot objects
	move_and_rotate_total_pivot(0) - anim pivot (0 - last selected position , 1  - average,2 - first selected position, 3 - average, zero vertical position)
	bar_tail_overlap_window - overlapper window
	execute_overlap_command(int $chain, string $objects[], float $softness, float $lag,  0 , float $easing, int $cycle, int $abs_mode, int $save_pose) - execute overlap command
	overRig_noise_window - open noise window
	overRig_tween_window() - tween, overshoot or curve push menue

	create_recalc_spine_rig_menue() - bake to easy vertebra system menue
	bar_create_multiply_fast_motion_trail(int $start, int $end, int $static) - create fast Motion Trail
