barnev_Joint_Optimal_Pro_Application 

 Author: Pavel Barnev pavel_barnev2000@mail.ru 

This tool is intended for: 

    Full  toolset for creating and orienting skeletons
	most of these tools work not only with bones, but in general with any objects
     Include:
	 - several ways to create bones
	 - including a unique method of adding bones to a nonlinear chain
	 - tools for quickly parenting
	 - a set of tools for alignment, smoothing and bone distribution
	 - a set of tools for selection bones, including a unique tool for selection the shortest path between two bones
	 - a set of tools for orienting bones - automatic and manual
	 - tool for painting bones in various colors
	 - a set of tools for quick naming, searching for matching names for removing namespaces, etc.


Installation: 

    Unpack the .zip file to any place on the disk where you are comfortable 

    Open Maya. 

    Drag and drop file: 
    drag_and_drop_THIS_FILE_on_maya_window_for_install_Joint_Optimal_Pro_Application.mel 

    To an open MAYA window. An icon will appear in the Custom tab of the Shelf Editor.
