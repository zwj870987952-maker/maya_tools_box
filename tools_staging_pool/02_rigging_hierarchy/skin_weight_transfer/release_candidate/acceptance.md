# 骨骼权重批量转移真实 Maya 验收

1. 备份场景加载 `launch_candidate.py` 的 `show_ui()`，按源关节/目标关节/网格顺序选择并载入，完整路径多行显示，文本可编辑，按钮响应，Script Editor无致命错误。重开窗口只关本候选，不影响原脚本或其它窗口。
2. 三影响小网格分别赋0.2/0.3/0.5；A→B应为0/0.5/0.5，所有顶点均验证，源影响默认仍在。预检不改场景/选择/时间/Undo。执行一次Undo恢复原权重。
3. 模型省略时，确认计划仅源关节已连接的全部skin模型；多个模型按显式列表合并。歧义短名、重复transform/shape别名、缺失影响、锁/引用/实例、多个skin、保持最大影响数、DQ/驱动权重明确拒绝，不允许静默跳过。
4. 连续 A→B、B→C（同网格），最终A/B归零C累计；DelSkin移除A影响但保留A关节，单次Undo恢复影响列表和原数值。后一任务还用被移除A时，整批预检失败且前一任务未修改。
5. 未归一化skin权重例如0.8/0.4/0.8，A→B应0/0.6/0.4；总和为零行、极小数、大网格速度/影响锁/生产动画skin逐项检查；Undo恢复原未归一化值和skin设置。失败应检查并Undo本次，勿继续叠加任务。
6. 记录 Maya/Python、数据样例、耗时和未支持条件。真实GUI/生产rig/其它版本目前not_run；满意后才按promotion预制动作晋级，验收问题先修候选。候选及原字节留池，不提前改正式库，不运行Obsidian同步。
