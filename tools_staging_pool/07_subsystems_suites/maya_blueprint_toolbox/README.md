# Maya 蓝图工具盒（Maya Blueprint Toolbox）

在 Maya 内运行的 ComfyUI / 蓝图式节点画布：把 Maya 常见操作、数据获取、数据转换和动画工作流拆成可连接的节点，让用户不写代码即可搭建、保存、复用批处理流程。

- 界面全中文，面向中文团队的动画 / TA 管线场景。
- 兼容 PySide6（优先）与 PySide2 回退，目标覆盖 Maya 2020+。
- 不依赖第三方库，只使用 Maya 自带 Python 环境。

## 在 Maya 中运行

把本仓库所在目录加入 Maya 的 Python 路径，然后执行：

```python
import maya_blueprint_toolbox
maya_blueprint_toolbox.show()
```

如需每次启动 Maya 自动可用，可在 `userSetup.py` 里追加路径：

```python
import sys
sys.path.append(r"D:\jiaoben")  # maya_blueprint_toolbox 的父目录
```

## 功能总览

### 画布与交互

- 节点可拖动，带类型化输入 / 输出端口；节点头部颜色表示功能类型，端口与连线颜色表示数据类型。
- 从输出端口拖拽连线到类型兼容的输入端口；节点不能连接自身。
- 双击空白画布：打开节点搜索对话框，在光标处添加节点。
- 右键空白画布：按分类菜单添加节点（分类来自节点 `category`，按 `/` 分层）。
- 中键拖拽或 空格 + 左键拖拽平移画布，滚轮缩放。
- Delete / Backspace 删除选中的节点或连线。
- 右侧属性面板编辑选中节点的参数；`打印结果` 节点还会在面板中显示最近一次运行的值。

### 运行与校验

- `检查`：校验必填参数与必连端口，问题列表输出到 Script Editor。
- `运行`：有选中节点时，只执行选中节点及其上游依赖，其余节点标记「跳过」；未选中时执行全部节点。
- 运行按钮旁的数字控制执行次数，默认 1。
- 执行时按拓扑顺序逐节点运行，节点边框与头部标签实时显示状态：待机 / 运行 / 完成 / 错误 / 跳过。
- `打印流程`：把当前工作流序列化 JSON 打印到 Script Editor。

### 持久化

- 工作流可保存 / 加载为 JSON（含节点位置、参数、连线）。
- 加载时会做类型与连线兼容性校验，无法识别的节点与非法连线会被跳过。

### Maya 操作边界

- 所有 Maya 操作统一走 `maya_blueprint_toolbox/maya_api` 包装层，不在执行器里散落 `cmds` 调用。
- 会修改场景的操作包在 UndoChunk 中，错误统一抛出 `MayaApiError` 并转为执行错误提示。
- FBX 导出会自动加载 fbxmaya 插件，导出后恢复之前的 Maya 选择。

## 快速上手示例

### 属性引用流程（设置属性）

1. 在 Maya 里选中或记下一个 transform 节点。
2. 添加 `当前选择` 或 `节点名称`。
3. 添加 `创建属性引用`，在属性列表中加入 `translateX`，连接 `节点 -> 节点`。
4. 添加 `数字`，设置测试数值。
5. 添加 `设置属性`，连接 `属性引用 -> 属性引用`、`值 -> 值`。
6. 选中 `设置属性` 节点，点击 `运行`。

如需检查属性状态，把 `创建属性引用.属性引用` 连到 `检查属性.属性引用` 后运行，可得到当前值以及 keyable、writable、locked、connected、Maya 属性类型等信息。

### 复制帧（输出 JSON）

1. 在 Maya 里选中一个或多个 transform 控制器。
2. 添加 `当前选择`、`当前帧`、`变换通道`、`复制帧`。
3. 连接 `当前选择.节点 -> 复制帧.复制对象`、`当前帧.帧 -> 复制帧.帧`、`变换通道.通道 -> 复制帧.通道`。
4. 保持 `复制帧.帧数据` 输出口未连接，运行后会写出 JSON 文件；在节点参数 `JSON 路径` 里可指定文件位置，留空则写入系统临时目录。

### 复制帧（直接粘贴并打关键帧）

1. 按上面的方式搭好复制端。
2. 添加目标端 `节点名称` 或 `当前选择`，再添加 `创建属性引用`，属性填 `translateX, translateY, translateZ, rotateX, rotateY, rotateZ`。
3. 添加 `设置属性`。
4. 连接 `复制帧.帧数据 -> 设置属性.值`、`创建属性引用.属性引用 -> 设置属性.属性引用`。
5. 运行 `设置属性`：复制到的帧数据会写入匹配的目标属性，并在对应帧上设置关键帧。

注意：复制帧粘贴按「列表顺序 1 对 1」严格匹配，复制对象与粘贴对象数量必须相同。要调整对应关系时，在复制端或粘贴端插入 `按名称排序节点`、`反转节点列表`、`按层级排序节点` 等排序节点改变列表顺序，功能节点本身不做名称猜测。

## 已知限制与后续计划

当前限制（详见 `docs/project_assessment_report_2026-07-10.md`）：

- 暂无流程控制节点（条件、循环），执行模型是纯数据流拓扑执行。
- 复制帧能输出 JSON，但还没有对应的「从 JSON 加载帧数据」节点。
- 画布编辑（删除节点 / 连线）暂无撤销；Maya 场景操作有 UndoChunk。
- 暂无自动化测试。

后续计划：

- 补充更多 Maya 操作节点（复制节点、父子层级、冻结变换、删除历史等，见交接文档）。
- 执行器节点分发改为注册表机制。
- 若原生 Qt 画布交互不够用，再考虑在本地 `vendor` 目录内置经过批准的第三方 UI 库。
