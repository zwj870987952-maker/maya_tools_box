# Animo 人工 Maya 检验

当前状态：**全部未运行，等待用户检验**。离线测试不代表 Maya 检验通过。每个版本和入口需记录实际结果，不能把部分样例通过扩展为 553 项全部通过。

## 准备与启动

1. 使用场景副本，记录 Maya 版本、系统、帧率、长度/角度单位、Rig 名称与命名空间、动画层状态。
2. 按 [README](README.md) 的 Python 命令打开候选面板；确认能搜索 553 个入口并查看 JSON 说明，Script Editor 没有致命报错。
3. 使用安装预检，再安装运行副本。已有 `Animo_Data` 时应拒绝覆盖，并保留旧文件；自行备份移开后才能新装。
4. 打开原生工具栏。比对启动前后的 `userSetup.py` 与 `startupScriptIsEnabled`；在未主动配置自动启动的情况下应保持原值。确认无关工具窗口没有被关闭。原生偏好/UI 仍可能产生自身配置。

## 优先检查核心行为

| 项目 | 输入与步骤 | 观察与通过条件 |
| --- | --- | --- |
| 滑块 / Tween | 测试已有选帧和仅当前时间两种上下文；分别拖动、释放、Undo/Redo | 关键帧值及插帧符合预期；厘米/米、度/弧度转换正确；释放和异常后刷新及 Undo 正常 |
| Spacify / 临时轴心 | 对带命名空间控制器创建世界/摄像机/临时 IK 空间，再烘焙清理 | 运动、约束、节点选择符合预期；确认临时节点清理范围，Undo 结果正确 |
| Mirror | 非对称 Rig，左右命名与轴向，当前姿态、选帧、时间区间、动画层 | 配对和旋转轴正确，单侧/多层处理范围符合 UI 设置，未误改未选对象 |
| Transify | 同/异命名空间，姿态/动画复制粘贴，切线、Infinity、旋转顺序 | 目标通道和值正确；非根动画层的提示符合预期；不得假设完整层结构无损转移 |
| Vectorify / Tracify | 已有运动角色沿路径；显示/隐藏轨迹 | 时间区间和运动符合预期，插件/UI 可正常关闭，无致命错误 |
| 对齐 / 约束 / 烘焙 | 简单父子层级，多对象有序选择，带约束与动画的副本 | 选中范围、空间、父级与帧范围正确；分派后的最终选择和 Undo 正常 |
| 曲线 / 切线 / 关键帧 | Graph Editor 选帧、通道筛选、时间选区和空选择 | 修改范围正确，空选择有合理提示，无未预期全场景改动 |
| 工具编辑器 / 选择集 | 搜索、打开子面板、保存/恢复选择、关闭与重开 | 按钮/快捷键响应正常，重复开启不产生多套无效窗口或定时器 |
| 多摄像机预览 / 导出 | 专用临时输出目录，小场景与短帧段，查看生成文件 | 摄像机/区间/格式和输出路径正确；外部文件不由 Maya Undo 撤回 |
| Reference Dropper | 少量测试图片/视频，专用临时输出目录 | FFmpeg 和图片序列输出正常，引用/图片节点符合预期，清理时不影响其他资源 |

预检入口可用但原生业务前提未检查时，记录实际原生提示/取消；`success=True` + `state=dispatched_unverified` 仅证明入口已调用。部分 UI 回调发生在 `run()` 返回之后，其 Undo 由原工具管理，不能认为框架将整段交互自动包成一次撤销。

## 逐项记录与转正条件

在 [acceptance.json](acceptance.json) 中填写版本、场景、时间和测试者。每项 `status` 用 `passed` / `failed` / `not_run`，补充预期、观察、Undo、Script Editor 错误和证据。未运行项继续保留 `not_run`；更改算法或入口后应重验受影响项。

正式迁移前须确认人工检验范围及问题修复结果，保留原始来源和调整记录，再单独处理正式注册、面板接入和回归。用户确认取得的发布授权见 [记录](../AUTHOR_PERMISSION.md)，它不改变尚未进行 Maya 实测的状态。
