# Maya 外部 FBX 资产比对与差异同步工具

> 工具 ID：`compare_and_sync_fbx`。正式库状态不代表所有引擎、版本和场景均已验证。
>
> 比对工具支持的网格统计、UV 集、材质分配及变换信息，并按明确目标同步材质或变换。比对覆盖的字段有限，不能据此认定整个资产完全一致。
>
> 本页修正文档入口与使用边界，没有新增 Maya 实测记录。API 参数以 [调用速查](../llm_tools_cheatsheet.md) 为入口，框架行为以 [开发契约](../../DEVELOPMENT_SPEC.md) 为准。

## 🌟 启动与环境准备

仓库附带部分 FBX SDK 运行文件。能否加载取决于操作系统、Python ABI、Maya 版本及依赖状态；复制仓库不等于完成环境适配。先确认目标环境与读取引擎，再验证实际比对和同步。

### 方法一：统一工具架入口
1. 打开目标 Maya 实例。
2. 将仓库根目录的 **`drag_and_drop_install.mel`** 拖入 Maya 3D 视口，按 [项目主页](../../README.md) 的统一启动器流程使用。
3. 从工具箱中打开 FBX 比对工具。安装按钮或打开窗口只证明启动步骤完成，不证明 SDK 加载、比对和同步已通过验收。

---

### 💻 方法二：脚本编辑器一键启动 (临时使用或集成流水线)
打开 Maya **脚本编辑器 (Script Editor)** -> 切换到 **Python** 标签页，粘贴并运行以下代码（请将路径换为当前工具所在文件夹）：

```python
import sys

# 替换为您存放工具的具体文件夹路径
tool_dir = r"D:/path/to/maya_tools_box"

if tool_dir not in sys.path:
    sys.path.insert(0, tool_dir)

import maya_toolkit
maya_toolkit.show_ui()  # 在统一面板中选择 FBX 比对工具
```

### FBX SDK 安装辅助
- 根目录的 `install.bat` 是环境安装辅助入口，不是业务工具启动入口。使用前需确认其目标 Maya/Python 环境与安装位置；本页不保证它能发现所有安装布局或覆盖所有 Maya 版本。
- 安装会写入运行环境文件，不属于 Maya 场景 Undo 的范围。已有可用环境时无需仅为打开工具而重复安装。
- 历史模块位于 `compat/`，仅把仓库根目录加入路径后，不应继续使用旧的根目录 `import import_fbx_materials_to_matching_objects` 示例。优先使用上面的统一面板或文档中的公开调度入口。

## 🛠️ 运行文件与读取引擎的边界

| 仓库资源/模式 | 可以说明的范围 | 使用前仍需确认 |
| :--- | :--- | :--- |
| `fbx_sdk_dist/python310/` | 包含面向 CPython 3.10 的 Windows 二进制文件 | 当前 Maya 的 Python ABI、操作系统和依赖是否匹配，SDK 能否实际加载 |
| `fbx_sdk_dist/python311/` | 包含面向 CPython 3.11 的 Windows 二进制文件 | 同上；文件存在不代表该 Maya 环境已实测 |
| FBX SDK 读取模式 | 可通过 SDK 解析外部文件，无需据此导入场景模型 | 本次实际使用的引擎、返回字段及错误信息 |
| 原说明中的沙箱后备模式 | 涉及临时加载与清理，不能沿用“绝不导入模型”的描述 | 是否在当前入口可用、临时对象及状态是否完整清理；失败恢复需单独验证 |

兼容范围以对应工具版本、引擎和 Maya 环境的实测记录为准。本页不再把资源目录或预期兼容版本当作已验证版本矩阵。`diff_only` 是执行比对的业务动作，与仅调用 `validate()` 的 `dry_run=True` 不同；不能仅凭动作名称推断整个读取过程没有副作用。

> **提示**：如果您的工作站有特定外置 FBX SDK 路径，可在界面顶部 `自定义 SDK 路径` 输入框中填入并点击 `加载 SDK` 随时热切换。

## 📋 功能特点与操作指南

### 1. 🔍 资产字段比对
- 载入外部 FBX 后，使用界面的比对操作，查看返回的分类及字段。以下为状态含义，具体检查范围以当前引擎实际输出为准：
  - **🟢 完全吻合**：在本次工具检查的字段和判定规则内未发现差异，不代表全部几何、贴图网络或渲染效果一致。
  - **🟡 材质差异**：所检查的材质信息或分面分配存在差异，不据此推断其他未检查字段一致。
  - **🟠 变换差异**：所检查的位移、旋转或缩放存在差异。
  - **🔴 拓扑冲突**：顶点数、多边形面数或三角化面数不同，标记风险。
  - **⚪ 单侧缺失**：仅存在于 Maya 场景或仅存在于外部 FBX 文件中。

### 2. 🗂️ 动态过滤器与实时搜索
- 顶部过滤器标签提供实时数量徽章（如 `全部 (12)`、`仅差异 (5)`、`材质差异 (2)`、`拓扑冲突 (1)` 等）。
- 支持在搜索框中实时根据资产名称过滤显示。

### 3. 📊 逐项双列对照详情卡片 (Side-by-Side Inspector)
- 在上方列表中单击选中任意资产，下方即刻展现该资产在 **Maya 场景** 与 **外部 FBX** 的逐项对比：
  - 顶点总数 (Vertices)、面数 (Polygons)、三角面数 (Triangles)
  - UV 通道集 (UV Sets)
  - 关联材质球列表与分面区间 (Face Assignments)
  - 空间坐标位移 (Translation)、旋转 (Rotation)、缩放 (Scaling)

### 4. ⚡ 按目标同步差异
- **✨ 一键同步选中材质与分面**：
  - 将外部 FBX 中工具支持的材质信息与分面指派应用到目标资产，不承诺完整重建所有渲染器的材质网络。
  - 若发生整物主材质回退，分面效果会改变，不能视为分面传递完全成功。应检查警告、实际分配和任务要求；面数相同本身也不能证明面索引对应。
- **📐 一键同步选中变换**：
  - 同步目标资产的变换信息；操作前核对源目标对应关系、层级与坐标语义，操作后检查实际位置和姿态。
- **🎯 视口高亮对焦选中项**：
  - 在列表中选中资产后，点击此按钮可直接在 Maya 3D 视口和大纲视图中选择并自动对焦（Frame）该物体。
- **📄 导出核查报告**：
  - 一键将本次比对的完整资产清单、状态及差异指标导出为高可读性的 Markdown 文档，便于团队交接与美术质检。

API 的 `target_assets` 用于限制同步资产；省略或留空会作用于所有检出的差异项，不能等同于界面选中项。短名称匹配存在歧义时，应先确认匹配关系再同步。调用示例见 [API 速查](../llm_tools_cheatsheet.md)。

### 5. 🛡️ 撤销、失败处理与结果验收
- 统一框架通过 Undo Chunk 对执行阶段的场景操作分组；实际可撤销范围取决于具体操作。UI 回调是否在同一分组内需分别验证，不能把框架分组当作全部界面操作的保证。
- Undo Chunk 不会在异常时自动回滚已发生的修改。部分失败后，先确认已改动的目标、临时对象和当前状态，再决定恢复或重试。
- 报告导出、SDK 安装和其他外部文件写入不由 Maya Undo 撤回。
- 验收时查看结果、错误与警告，并检查目标材质/变换、非目标对象是否保持原状，以及读取过程中临时状态的清理情况。打开窗口、预检通过或返回成功标志，都不能单独代替业务结果检查。
