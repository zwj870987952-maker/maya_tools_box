# Maya时间轴工具使用说明

## 工具介绍

这是一个类似Maya时间轴的交互界面工具，支持在时间轴上放置和拖拽方块，可用于动画时序规划、关键帧标记等用途。

## 主要功能

### 1. 时间轴显示
- 显示可自定义的时间轴范围
- 每帧都有明确的帧数标识
- 支持水平滚动查看更多帧

### 2. 方块管理
- 在任意帧上添加彩色方块
- 支持多种颜色的方块
- 每个方块可以有自定义标签

### 3. 拖拽功能
- 点击有方块的帧开始拖拽
- 拖拽过程中方块变为黄色提示
- 点击目标帧完成拖拽操作

## 使用方法

### 启动工具

在Maya脚本编辑器中运行：

```python
# 方法1：直接运行
exec(open(r"D:\jiaoben\maya_timeline_tool.py").read())

# 方法2：导入并运行
from maya_timeline_tool import show_timeline_tool
show_timeline_tool()
```

### 界面操作

#### 控制面板
- **起始帧**：设置时间轴的起始帧数
- **帧数**：设置时间轴显示的总帧数
- **添加方块**：随机在某一帧添加彩色方块
- **清空所有方块**：删除时间轴上的所有方块

#### 时间轴操作
1. **添加方块**：点击空帧直接添加绿色方块
2. **开始拖拽**：点击有方块的帧，方块变黄色进入拖拽状态
3. **放置方块**：拖拽状态下点击目标帧完成移动
4. **取消拖拽**：点击"清空所有方块"或重新点击其他方块

## 自定义使用

### 添加自定义方块

```python
# 创建工具实例
tool = show_timeline_tool()

# 添加自定义方块
block_data = {
    "color": (1.0, 0.0, 0.0),  # RGB颜色值 (红色)
    "label": "Key"             # 方块标签
}
tool.add_block(10, block_data)  # 在第10帧添加方块
```

### 设置快捷键

```python
# 运行示例文件中的快捷键设置
exec(open(r"D:\jiaoben\maya_timeline_tool_example.py").read())
timeline_tool_hotkey_setup()
```

设置后可使用 `Ctrl+Shift+T` 快速启动工具。

## 应用场景

### 1. 动画时序规划

- 不同颜色代表不同类型的动画事件
- 通过拖拽调整动画时序安排

### 2. 关键帧管理
- 标记重要的关键帧位置
- 可视化动画节奏和时间分配
- 方便团队沟通动画时序

### 3. 镜头分割
- 标记镜头切换点
- 不同颜色表示不同镜头类型
- 辅助剪辑和后期制作规划

## 故障排除

### 常见问题
1. **窗口无法显示**：检查Maya版本兼容性
2. **拖拽不响应**：确保先点击有方块的帧
3. **界面布局异常**：尝试关闭重新打开工具
4. **颜色显示异常**：检查颜色值范围(0.0-1.0)
