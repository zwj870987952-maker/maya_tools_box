To install :

1 Close Maya
2 Place the 'bh_localNudge.mel' file in your Documents>Maya>(Maya version)>Scripts folder
3 Restart Maya
4 to launch the tool type : bh_localNudge; and hit enter

An Icon file (bhLocalNudge.png) is supplied if you'd like to add the command to a shelf and have an icon for it.
